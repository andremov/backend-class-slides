# Proyecto 01

<h2 class="center serif">Desarrollo Web Backend</h2>

Desarrollen el backend que unan todos los talleres desarrollados en clase.

- La API debe formar parte del repositorio en Github de talleres y debe ser "entregada" al profesor utilizando el enlace en el catalogo, donde **se enviará únicamente el enlace al repositorio.**
- El proyecto se desarrolla de manera individual, con fecha de entrega **viernes, 7 de noviembre a las 23:59.**

### Estructura a Desarrollar

- El repositorio debe tener los archivos basicos y esenciales de un backend
- Cada taller debe tener su archivo de rutas
- Los archivos correspondientes a los talleres deben exportar las funciones contenidas para ser utilizadas por el archivo de rutas.
- Las rutas creadas para cada uno de los talleres deben realizar la responsabilidad de las rutas (toda la logica HTTP)
- Cada punto de un taller pasado, es decir cada función del archivo de taller debe tener su propio endpoint en el archivo de rutas correspondientes.
- Todos los endpoints son de tipo POST, y envían los parametros relevantes en el body del request. La ruta es a consideración del estudiante.
